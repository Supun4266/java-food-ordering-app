# 🍔 Java Food Ordering App

A simple console food ordering app built with Java.
The customer picks food from a menu, chooses how many, and gets a bill with a discount for big orders.

## Features
- Shows a menu of food items with prices
- Customer can order multiple items and quantities
- Calculates the total bill
- Gives a 200 discount on orders over 2000
- Checks for invalid menu choices

## How to run
You need Java 17 or newer.

```
javac *.java
java Main
```

## Example
```
--- Menu ---
1. Burger - 500
2. Pizza - 800
Choose a food number: 2
How many? 3
Added 3 x Pizza = 2400
```
